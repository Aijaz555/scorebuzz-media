## Lessons
- Club, team and star names are by far the biggest searches: always put them in the title and first sentence.
- "premier league predictions" is growing fast and easy to rank for; use "<league> predictions" titles on prediction boards.
- Don't use generic "live score", "live match", "today match live": that traffic is almost all cricket / South Asia (wrong audience). Use "<Team> vs <Team> live" and "<league> live" instead.
- "highlights" terms are huge but we show no footage, so never use them (misleading = YouTube penalty).
