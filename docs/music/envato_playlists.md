# Envato Elements playlists for the live streams (picked 8 Nov 2026)

Picked from elements.envato.com searches (nba, nfl, mlb, nhl, premier league, serie a, soccer): full-length tracks only
(no 6–30 s logo idents), energetic but not distracting under a scoreboard, 1:30–3:30 each so a playlist runs ~25–35 min
before it loops. Download each one from your Envato Elements account (it needs the subscription login, which Claude
doesn't have), then add the files to the LiveReacting media library (Studio → Media) or share a Google Drive / Dropbox
folder link and Claude imports them with livereacting_import_media and builds the playlists.

**Licence:** when downloading, register each track to a project called "ScoreBuzz live streams" so the licence certificate
is generated; keep the certificates. If YouTube raises a Content ID claim on a stream, dispute it with that certificate.
Check Envato's licence page covers broadcast/streaming use for your plan before relying on it.
